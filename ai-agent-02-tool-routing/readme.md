# Project Goal

This project demonstrates how an AI agent routes user requests to the correct tools.

## Features

- Rule-based tool routing
- Single-tool and multi-tool selection
- Inventory / shipment / KPI analysis use cases
- Extensible design for embedding and LLM-based routing

## Example Queries

- 查詢 CB602 成品庫存
- 幫我看 CB602 原料庫存
- 查 CB602 規格
- 幫我分析 CB602 庫存與出貨風險

## Roadmap

- **v1:** Rule-based router
- **v2:** Embedding similarity router
- **v3:** LLM router
